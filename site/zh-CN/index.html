会跟着你的布局一起动的壁纸。

niri 的视差壁纸守护进程。在窗口之间、工作区之间移动时，壁纸会朝同一方向移动几十像素。

安装 在 GitHub 查看
機能

守护进程自己就是壁纸。

这里列的都在 0.1.0 里。

視差

跟随焦点的视差

在列与工作区之间移动时，壁纸朝同一方向移动。步长来自固定的 column_span 与 workspace_span，所以开关窗口不会让壁纸跳动。

単一

没有辅助进程

一个二进制在 background 层放一个 layer-shell 表面，直接往里渲染。没有 mpv 进程，没有 shell 脚本。没有东西在动时不出帧。

動画

视频壁纸，硬件解码

mp4、webm、mkv、mov、m4v、avi 和 gif。mpv 在这里是库，把解码好的帧画进守护进程自己的纹理，所以视频和静态图一样按视差偏移采样。

同期

和 niri 同步

开启 follow_niri 后，总览过渡的弹簧或缓动曲线取自 niri 自己的配置。打开总览时，壁纸跟着一起缩小。

設定

一个配置文件，按输出分别配置

缩放、跨度、壁纸都可以每个输出不一样。单一的 config.toml 在守护进程运行时就会被读取；解析失败的文件不会影响正在运行的配置。

アプリ

其余的交给桌面应用

一个 Tauri 窗口：浏览本地库或 Wallhaven、带着滤镜预览、选择显示器，以及改过渡、视差和轮播。它通过控制 socket 发送 set 与 next，并就地改写配置文件。界面是中文。

転換

八种换壁纸的方式。

每段动画都是守护进程自己的 shader 逐帧渲染出来的，不是 CSS 的仿制。鼠标悬停或键盘聚焦即可播放。设置 effect = "none" 可以关掉过渡。

導入

安装。

版本 0.1.0，早期。需要 niri（开发时用的是 26.04）和 libmpv。

预编译二进制
运行 mpv --version，它报告的版本是：

下载压缩包

curl -LO https://github.com/harukizmoe/niripaper/releases/download/v0.1.0/niripaper-v0.1.0-x86_64-linux-gnu-mpv0.41.tar.gz
mkdir niripaper-release
tar xzf niripaper-v0.1.0-x86_64-linux-gnu-mpv0.41.tar.gz -C niripaper-release
install -Dm755 niripaper-release/niripaper niripaper-release/niripaper-app -t ~/.local/bin

压缩包里有守护进程 niripaper、桌面应用 niripaper-app 和一份 INSTALL.txt。两个版本都需要 glibc 2.34 或更新。守护进程运行时需要 libmpv、libEGL、libgbm 和 libwayland-client；桌面应用还需要 webkit2gtk-4.1 和 libayatana-appindicator3。ldd ./niripaper 会列出缺的库。请让 ~/.local/bin 在 PATH 上，否则 niri 启动时找不到它。

从源码编译

守护进程是手写 FFI 直接链接 libmpv、libEGL、libGL、libgbm 和 libwayland-client 的，所以编译时要有它们的开发文件。Arch 上是 mpv、libglvnd、mesa、wayland。

git clone https://github.com/harukizmoe/niripaper.git
cd niripaper
cargo install --path . --locked --bin niripaper

--bin niripaper 不能省。不带它的话，src/bin/ 里的诊断探针也会和守护进程一起被装上。

AUR

仓库里有一份 PKGBUILD，但还没有发布：AUR 目前不接受新账号。

跟随 niri 启动

把这行加进 ~/.config/niri/config.kdl。二进制必须在 PATH 上。

spawn-at-startup "niripaper" "daemon"

铺满整个总览背景

默认情况下壁纸是工作区背景：它随工作区滚动。加上这条 layer rule，壁纸就固定不动，并放在总览的背后。

layer-rule {
    match namespace="^niripaper$"
    place-within-backdrop true
}

配置

配置文件是可选的，守护进程运行时修改会被读取。取值的优先级是：命令行，然后配置文件，最后是内置默认值。

# ~/.config/niripaper/config.toml
wallpaper = "~/Pictures/wall.webp"
scale = 1.1                # 越大，可移动的余地越多

[transition]
selection = "rotate"       # fixed | rotate | random
effects = ["portal", "iris", "dissolve"]
