A wallpaper that moves with your layout.

A parallax wallpaper daemon for niri. The wallpaper shifts a few dozen pixels as you move between windows and workspaces.

Install View on GitHub
機能

The daemon is the wallpaper.

Everything here is in the 0.1.0 release.

視差

Parallax that follows focus

Moving between columns and workspaces shifts the wallpaper in the same direction. The step comes from fixed column_span and workspace_span values, so opening or closing a window never makes it jump.

単一

No helper processes

One binary puts a layer-shell surface on the background layer and renders into it. No mpv process, no shell scripts. While nothing is moving it draws no frames.

動画

Video wallpapers, hardware-decoded

mp4, webm, mkv, mov, m4v, avi and gif. libmpv is used as a library and draws into a texture the daemon owns, so a video gets the same parallax as a still.

同期

Moves in step with niri

With follow_niri on, the overview transition takes its spring or easing curve from niri's own config. Opening the overview zooms the wallpaper out with it.

設定

One config file, per output

Scale, spans and wallpaper can differ per output. A single config.toml is picked up while the daemon runs, and a file that fails to parse leaves the running configuration alone.

アプリ

A desktop app for the rest

A Tauri window browses the local library or Wallhaven, previews filters, picks the monitor, and edits transitions, parallax and rotation. It sends set and next over the control socket and edits the config in place. Its interface is in Chinese.

転換

Eight ways to swap a wallpaper.

Each clip is the daemon's own shader rendered frame by frame, not a CSS imitation. Hover or focus a clip to play it. Set effect = "none" to turn the transition off.

導入

Install.

Version 0.1.0, early. Needs niri (developed against 26.04) and libmpv.

Release binary
Run mpv --version. It reports:

Download tarball

curl -LO https://github.com/harukizmoe/niripaper/releases/download/v0.1.0/niripaper-v0.1.0-x86_64-linux-gnu-mpv0.41.tar.gz
mkdir niripaper-release
tar xzf niripaper-v0.1.0-x86_64-linux-gnu-mpv0.41.tar.gz -C niripaper-release
install -Dm755 niripaper-release/niripaper niripaper-release/niripaper-app -t ~/.local/bin

The tarball holds the daemon niripaper, the desktop app niripaper-app and an INSTALL.txt. Both builds need glibc 2.34 or newer. The daemon needs libmpv, libEGL, libgbm and libwayland-client at run time; the app also needs webkit2gtk-4.1 and libayatana-appindicator3. ldd ./niripaper shows what is missing. Keep ~/.local/bin on PATH, or niri will not find it at startup.

Build from source

The daemon links libmpv, libEGL, libGL, libgbm and libwayland-client by hand, so their development files are needed. On Arch: mpv, libglvnd, mesa, wayland.

git clone https://github.com/harukizmoe/niripaper.git
cd niripaper
cargo install --path . --locked --bin niripaper

--bin niripaper is not optional. Without it the diagnostic probes in src/bin/ are installed alongside the daemon.

AUR

A PKGBUILD exists, but it is not published: the AUR is not accepting new accounts.

Start it with niri

Put this in ~/.config/niri/config.kdl. The binary has to be on PATH.

spawn-at-startup "niripaper" "daemon"

Fill the whole overview backdrop

By default the wallpaper is a workspace background: it scrolls with the workspace. This layer rule makes it stationary and puts it behind the overview.

layer-rule {
    match namespace="^niripaper$"
    place-within-backdrop true
}

Configure

The file is optional and edits are picked up while the daemon runs. Values resolve as command line, then file, then built-in default.

# ~/.config/niripaper/config.toml
wallpaper = "~/Pictures/wall.webp"
scale = 1.1                # larger leaves more room to move in

[transition]
selection = "rotate"       # fixed | rotate | random
effects = ["portal", "iris", "dissolve"]
